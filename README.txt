FOOTBALL SQUARES

Extract the ZIP, then open index.html in Firefox or another browser.
Keep teams.js, college-teams.js and the logos folder alongside index.html.

Edit index.html in Kate or VS Code to change the page styling and behavior.
Team lists are in teams.js and college-teams.js.

To use on GitHub Pages, upload the contents of this folder to your repository.
Includes the blank board, NFL and college selectors, payout calculator and printing.
